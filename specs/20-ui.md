# Screens

Every screen is its own page, linked with trailing-slash URLs; forms and confirmations are
pages reached by a link and left through `?return=`. No dialogs, no modals, no client
router. Build from the template's components; the reference
`/home/jamz/workspace/rosarp/w3mail/src/pages/` and `src/components/mail/` are for the screen list and layout only
(they use Flowbite from a CDN, which is not allowed here).

Navigation (`nav.js`): Inbox, Sent, Drafts, Trash, Contacts, Settings. A Compose button is
always visible in the header area and on the mobile tab bar.

## `/` Home
Mailbox status. While setting up: the steps (account, register key) with progress, and
what each prompt is for. When ready: unread count and "Open inbox".

## `/inbox/`, `/sent/`, `/trash/`
- Dense list rows: sender or recipient (contact name if known, else short address with
  avatar), subject, first line of the body, time. Unread rows bold with a dot; expired rows
  muted with an "Expired" badge.
- A row opens `/read/?msgId=…&return=<this page>`.
- Inbox has Sync with a "Last synced" time. Empty states: "No mail yet", "Nothing sent
  yet", "Trash is empty". Skeleton rows while loading.
- Trash rows have Restore and "Delete for good" (to `/purge/`).

## `/read/?msgId=&return=`
Subject, sender, recipient, time, body (plain text, line breaks kept). Actions: Reply
(`/compose/?to=…&subject=Re: …&return=…`), Move to trash, Back. Opening marks it read. An
expired message explains it was not synced within about two weeks.

## `/compose/?to=&subject=&draft=&return=`
To (address or a contact chosen from a select under the field), Subject, Body. Send shows
progress steps (encrypting, storing, sending) and returns to `return` (default `/sent/`)
with a toast. Discard deletes the draft and returns. Errors inline above the button.

## `/drafts/`
Saved drafts, newest first; a row opens compose with `draft=`. Delete per row.

## `/purge/?msgId=&return=`
Confirmation page: "Delete this message for good? It is removed from your mailbox on chain
and from this device." Delete and Cancel.

## `/contacts/` and `/contacts/edit/?id=&return=`
List of contacts with name and short address, "Write" (to compose) and "Edit". The edit
page adds or changes a contact (name, address, validated) and can remove it.

## `/settings/`
Account (name, address, H160; on the local chain the dev account and a link to switch),
mailbox key status (registered / not registered / changed, with Register again),
storage allowance status, last sync and a Sync now button.

## States
Every list has loading, empty and error states. Outside the host every page shows the
"Open in the Polkadot app" state.
